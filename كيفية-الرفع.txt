   دليل رفع تطبيق «الباقيات الصالحات» — بالتفصيل
════════════════════════════════════════════════════════

⚠️ سبب توقّف التطبيق سابقاً:
رفعتَ ملفات المصدر (مجلد src) بجانب ملف النشر، فحدث تعارض.
الحل: ارفع «ملفات النشر فقط» الموجودة في هذا المجلد — لا أكثر.

────────────────────────────────────────────────────────
الملفات التي ترفعها (كلها في هذا المجلد):
────────────────────────────────────────────────────────
  ✅ index.html          ← التطبيق كامل بداخله (الأهم)
  ✅ sw.js               ← العمل دون إنترنت والتحديث التلقائي
  ✅ manifest.json       ← أيقونة التطبيق عند التثبيت
  ✅ netlify.toml        ← إعدادات النشر
  ✅ _headers            ← إعدادات الأمان
  ✅ .nojekyll           ← ملف فارغ ضروري
  ✅ مجلد assets/        ← الشعار والأيقونات (7 ملفات)

❌ لا ترفع أي مجلد اسمه «src» — هو للتطوير فقط ولا علاقة له بالنشر.

────────────────────────────────────────────────────────
الطريقة الأسهل (بلا أخطاء) — عبر GitHub:
────────────────────────────────────────────────────────
1) افتح مستودعك على GitHub.
2) احذف كل الملفات القديمة الموجودة فيه أولاً (لتفادي التعارض):
   - اضغط على كل ملف/مجلد قديم ← أيقونة سلة المهملات ← Commit.
   - أو الأسهل: أنشئ مستودعاً جديداً نظيفاً.
3) اضغط: Add file ← Upload files.
4) اسحب «محتويات هذا المجلد» (الملفات السبعة + مجلد assets) وأفلتها.
   مهم: يجب أن يكون index.html في الجذر مباشرة، لا داخل مجلد.
5) اكتب رسالة أسفل الصفحة ← Commit changes.
6) Netlify سينشر تلقائياً خلال ثوانٍ.

────────────────────────────────────────────────────────
أو الأسرع — عبر Netlify مباشرة (Drag & Drop):
────────────────────────────────────────────────────────
1) ادخل: https://app.netlify.com/drop
2) اسحب «هذا المجلد كاملاً» وأفلته.
3) سيعطيك رابطاً فوراً. (لربطه باسمك القديم: Site settings ← Change site name)

────────────────────────────────────────────────────────
بعد الرفع:
────────────────────────────────────────────────────────
• افتح الرابط بمتصفح Chrome.
• إن ظهرت نسخة قديمة: أغلق التبويب وافتحه مرة أو مرتين
  (رفعنا نسخة الكاش إلى v18 فيتحدّث تلقائياً).
• للتثبيت: قائمة Chrome (⋮) ← «تثبيت التطبيق».

نسألكم الدعاء للمرحوم شاكر محمود الجبوري بالرحمة والمغفرة 🤍
